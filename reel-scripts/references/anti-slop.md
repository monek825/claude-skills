# Anti-slop (run on every draft)

AI-written scripts sound alike in predictable ways, and viewers have learned to scroll past them. Any hit below means rewrite that line. This list adds to the `stop-slop` skill; use both.

## Banned patterns
| Pattern | Example | Fix |
|---|---|---|
| Three-fragment list | "Satu halaman. Produk paling depan. Tombol pesan." / "It's fast. It's easy. It's effective." | One full sentence with the most important item, or just two items |
| "Not X, it's Y" contrast | "Ini bukan website, ini mesin penjualan." | State Y directly |
| Rhetorical Q&A list | "Harga? Murah. Kualitas? Tinggi." | A real sentence with a real detail |
| Meta commentary | "Di video ini…", "Let's dive in", "Ternyata ada twist-nya" | Delete; start with the content |
| Greetings and intros | "Halo semua", "Hey guys", "So…" | Delete |
| Hype adjectives | "luar biasa", "game changer", "insane", "next level", "revolusioner" | A specific detail that shows it |
| Slogan lines | "Website untuk masa depanmu." "Your brand, elevated." | Cut, or replace with a concrete benefit |
| Vague declaratives | "Kesan pertama itu penting." | Name the specific moment ("pembeli lihat logo dan dua paragraf") |
| Fake scenarios | "Bayangkan kamu sedang berjalan…" | Show a real, recognisable moment |
| Quotable closers | A line that sounds like a poster | Rewrite it as something a person would say out loud |
| Fake suspense | "Tunggu sampai akhir", "You won't believe" | Deliver sooner |
| Stacked tags | "[reverent] [softly] [warm]" on one line | One or two tags, only where the tone changes |
| Em dashes | — | Use a full stop or a comma |
| Invented proof | "Omzet naik 300%", "dipercaya 100+ brand" | Cut it; use only real, sourced facts |

## Rules for good lines
- **One idea per sentence.** Vary the length: a short line after a long one hits harder.
- **Concrete over abstract:** a screen, a chat bubble, a packet, a number the viewer can check.
- **Customer words.** Use what buyers actually type ("kak ini masih ada?", "ini asli nggak?", "nanti aja").
- **A human doing something.** Every sentence has a person acting, not "the website delivers".
- **Humour from truth.** The funniest lines are honest admissions ("kalau keripiknya nggak enak, website nggak bakal nolong").
- **Read it aloud.** If you wouldn't say it to a friend, rewrite it.

## Final pass
Search the draft for these and fix every hit:
- "bukan… tapi", "ini bukan"
- "bayangkan", "luar biasa", "di video ini"
- "—"
- three short fragments in a row
- any number without a source
